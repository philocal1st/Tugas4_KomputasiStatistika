### Tugas 4 - Sebaran Diskrit

Repository ini berisi tugas mengenai Sebaran Diskrit menggunakan bahasa pemrograman R.
### Materi yang Dikerjakan
1. Sebaran Poisson
   - Rata-rata pelanggan datang = 3 orang per jam
   - Menghitung peluang \(P(X \geq 5)\)
2. Sebaran Hipergeometrik
   - Populasi = 100 bola
   - Bola merah = 20
   - Sampel = 10 bola
   - Pengambilan dilakukan tanpa pengembalian
3. Sebaran Binomial
   - \(n = 15\)
   - \(p = 0.4\)
   - Simulasi sebanyak 1.000 percobaan
   - Perbandingan histogram hasil simulasi dengan PMF teoretis
